# Team 01 — Reference Intelligence & Site Reverse Engineering

## Mission
فهم الموقع المرجعي كمنظومة كاملة، وليس كمظهر بصري فقط.

## يوثق
- Header / Footer / Navigation / Mega menus
- كل صفحة وعائلة صفحات
- Products / Features / Solutions / Use cases
- Audiences / Pricing / Free tools / Resources / Enterprise
- User journeys / Conversion paths
- CTA destinations / Page relationships
- Interaction logic / Responsive behavior / Motion behavior
- Information architecture / Reusable patterns

## Evidence Model
- VERIFIED
- PARTIALLY VERIFIED
- INFERRED
- UNKNOWN
- TO CAPTURE

## لا يفعل
- لا يصمم ORBITS
- لا يعتمد قرارات
- لا يختصر تفاصيل المرجع
- لا يدخل Login بدون طلب صريح

## المخرجات
1. Master Reference Inventory
2. Page Map
3. Product/Feature/Solution/Audience/Pricing Matrix
4. User Journey Map
5. Interaction Inventory
6. Gap List
