## قواعد الاستخدام

استخدم `BrandLogo` من `src/components/brand-logo.tsx` في جميع مواضع أيقونة العلامة، بما فيها المواضع الجديدة مستقبلًا.
المكوّن يستدعي الصورة الأصلية مباشرة كقناع CSS، ولا يعتمد على نسخة SVG أخرى قابلة للتباعد عن المصدر.
غيّر اللون والحجم المتناسب فقط. لا تعِد الرسم أو التوليد أو التتبّع، ولا تغيّر الحدود أو الأشعة أو المسافات أو النسب أو الهوامش الأصلية. لا تضف مؤثرات أو ظلالًا أو حدودًا زخرفية.
هذه الأصول تمثّل الأيقونة فقط؛ النص الحالي ORBITS LINKS في الواجهة ليس جزءًا من الصورة المعتمدة.

## الاستخدام في الموقع

```tsx
import { BrandLogo } from "@/components/brand-logo";

// بجانب اسم العلامة أو داخل رابط له اسم متاح لقارئات الشاشة:
<BrandLogo />

// أيقونة مستقلة ذات معنى:
<BrandLogo label="ORBITS LINKS" />

// حجم أو لون خاص باستخدام CSS module:
<BrandLogo className={styles.customLogo} />
```

```css
.customLogo { width: 48px; color: #ffffff; }
```

اللون الافتراضي مركزي عبر `--brand-logo-color`: لون الحبر في الوضع الفاتح والليموني في الوضع الداكن؛ يتبع تفضيل النظام أيضًا عبر آلية المظهر الموجودة. صفحة Visibility تستخدم ألوان خلفياتها المحلية مع نفس المكوّن ونفس القناع.
استخدم `width` فقط للتحجيم، واترك نسبة الأبعاد 1:1. لا تعِد تنسيق عنصر الأيقونة بمؤثرات أو قص أو تمديد.

لتغيير لون SVG منفردًا، غيّر `color` في جذر الملف. عند إدراج SVG مباشرة في HTML يمكن ضبط `color` عبر CSS؛ أما إدراجه عبر `img` فلا يرث لون الصفحة. داخل React استخدم `BrandLogo` بدل نسخ SVG inline لتجنب تكرار معرف القناع.

## تحقق المرجع

عند إجراء تعديل على نظام الشعار، تحقق من بقاء بصمة PNG أعلاه ومن تطابق PNG المضمّنة في SVG مع الأصل. راجع العرض على خلفيتين فاتحة وداكنة وبحجمي الجوال وسطح المكتب.
